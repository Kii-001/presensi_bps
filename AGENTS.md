# Aturan Proyek: Presensi Mahasiswa Magang BPS Kota Medan

- PHP prosedural. Jangan buat class, interface, namespace, atau design pattern.
- Query selalu pakai PDO prepared statement.
- Nama variabel, tabel, dan kolom pakai bahasa Indonesia yang konsisten
  (contoh: $jam_masuk, $data_presensi).
- Komentar singkat dan seperlunya, bahasa Indonesia, hanya untuk logika penting.
- Jangan pakai emoji di kode maupun komentar.
- Jangan tulis komentar berawalan "ponytail:".
- Fitur di rancangan.md adalah wajib, jangan dikurangi atas nama minimalis.
- Kerjakan satu modul per permintaan, lalu berhenti dan jelaskan file apa yang dibuat.
